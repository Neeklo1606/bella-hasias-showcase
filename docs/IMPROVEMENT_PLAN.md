## Найденные проблемы

### Критично — безопасность
1. **Открыт `/.git/`** — любой может скачать весь исходный код и историю коммитов.
2. Открыты все `*.md` (в т.ч. `ENV_PRODUCTION.md`, `AUDIT_REPORT.md`), `package.json`, `laravel/composer.json`, `frontend/`, `src/`.
3. На сайте фейковые контакты-заглушки: `+7 999 123-45-67` (tel и WhatsApp), `bella@bellahasias.com` — нужно заменить на реальные.

### SEO / GEO
4. SPA: поисковик получает пустой `<div id="root">` и **одинаковые title/description на всех страницах**.
5. `/robots.txt`, `/sitemap.xml`, `/favicon.ico`, `/manifest.json` отдают HTML главной (файлы лежат только в `/build/`).
6. Несуществующие URL отвечают `200` (soft-404) — мусор в индексе.
7. Нет структурированных данных (JSON-LD): Person / ProfessionalService / Service / BreadcrumbList.
8. Sitemap статичный (февраль 2026), не знает про услуги из админки.
9. Нет `llms.txt` — описание сайта для AI-поисковиков (GEO).
10. OG-картинка по умолчанию в `PageSEO` указывает на несуществующий `/og-image.jpg`.

### Фавиконка
11. Подключён `logo3.png` (1536×1024, 214 КБ, не квадрат) вместо иконки. В `icons/` файлы с расширением `.png` на самом деле JPEG и неверных размеров. Нет `favicon.ico` в корне (Яндекс берёт именно его).

### Скорость
12. JS/CSS отдаются **без gzip** (в nginx включён gzip только для HTML) — 560 КБ JS вместо ~170 КБ.
13. Нет кэширования хешированных ассетов `/build/assets/*`.
14. Фото в бандле по 2–3 МБ (всего 47 МБ ассетов).

## Почему пропали фотографии
Сайт переведён на админ-панель: блоки «Услуги» и «Портфолио» на главной берут картинки из базы. При переезде на новый сервер (10.11.2026) в базу попали только тексты услуг: **0 медиафайлов, 0 кейсов, у услуг нет картинок**. Отсюда — пустые карточки услуг и «Нет работ в портфолио» на главной. Страница `/portfolio` берёт фото напрямую из файлов, поэтому там они есть. Файлы `frontend/src/data/*.json` для импорта (`cms:import-json`) содержат демо-заглушки, а не реальные работы.

**Решение сейчас:** если в базе нет картинок, сайт показывает реальные фото из репозитория (услуги — по slug, портфолио — 6 последних работ).
**Решение потом:** загрузить фото в админку (Медиа → Кейсы) — тогда сайт возьмёт их из базы.
